# Compact utility scout visual design

Use the supplied robot sheet as the visual starting point for one Modular AI Robotics chassis. The owner selected the reference with: “We should use this as a design for one of the robots.”

Reference image: [reference.jpg](reference.jpg). The image is preserved unchanged; its lettering does not select the robot's final name.

## Features to preserve

- An oversized head with two prominent blue optical lenses and an expressive face.
- Warm off-white armor over a dark mechanical frame, with amber indicator lights.
- A compact bipedal body, exposed joints and broad, stable feet.
- Practical gripper hands and visibly modular shoulders and equipment mounts.
- A friendly, capable industrial character, with restrained wear and a few distinctive cable loops.

## Adaptation across graphics packs

Preserve the silhouette and color contrast at normal gameplay distance across the [planned graphics packs](../graphics-quality-tiers-v0.1.0.md). Low should use chunky segmented geometry, simple lens shapes and a few strong mechanical details. Medium can add clearer panel layers and joints. High and optional Ultra can retain progressively more of the reference's detailed wiring, lens assemblies, armor layers, articulated hands and surface wear.

Simplification is a quality-tier choice rather than a rule for every version of this robot. Keep its proportions, equipment mounts, essential status cues and gameplay consistent across the packs.

Keep the face clear when adding equipment. A small back or side cargo module could support a courier variant while retaining the reference's head, arms and posture. Exact scale, collision shape and cargo arrangement remain design choices.

Use head tilts, optical brightness and body posture for idle, walking, greeting, waiting, blocked, working and inspecting animations. The reference's jets and holograms are optional visual ideas; flight and scanning capabilities have not been selected by this appearance decision.

## Chassis role

The recommended fit is a compact ground utility or scout companion. The appearance can support different installed tools and jobs through the project's shared controller architecture. This reference selects one robot's visual direction; it does not make every pictured activity a required feature or select it as the first courier's final chassis.
