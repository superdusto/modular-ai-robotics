# Segmented modular companion visual concept

The owner supplied this as another robot design idea. Its defining form is a tall rectangular companion with articulated panel segments, a small central blue optic and amber light strips.

Reference image: [reference.jpg](reference.jpg), preserved unchanged. The printed name is not a selected product name.

## Features to preserve

- A strong rectangular silhouette with two tall outer sections and a visible central mechanism.
- Hinged segments, compact manipulators and broad mechanical feet.
- Off-white panels, dark structural surfaces, amber seams and a blue focal optic.
- Expressive leaning, folding and gesturing through the robot's segmented body.

## Adaptation across graphics packs

Follow the [shared graphics pack plan](../graphics-quality-tiers-v0.1.0.md). Low can express the silhouette with a few articulated blocks and clear light strips. High and optional Ultra can expose layered hinges, locking mechanisms, recessed panels and surface wear while preserving the same proportions and equipment positions.

The image suggests a modular ground companion. Exact transformations, movement rules and installed tools remain gameplay design choices; the visual reference alone does not implement them.
